# Sapaan HP

Animasi sapaan saat HP dibuka (pagi/siang/sore/malam), teks muncul per huruf,
kilau pelangi transparan, bintang di kiri baris pertama, tarik ke atas untuk menutup.

## Cara build APK
**A. Android Studio (laptop):** File > Open folder ini > tunggu sync > Build > Build APK(s).
APK ada di app/build/outputs/apk/debug/app-debug.apk

**B. GitHub (tanpa Android Studio):** upload semua isi folder ini ke repo GitHub (branch main),
buka tab Actions > Build APK > tunggu selesai > unduh artifact "SapaanHP-apk".

## Pakai
Buka app > ikuti tombol 1-3 > Aktifkan. Pasang APK perlu izin "install dari sumber tidak dikenal".
